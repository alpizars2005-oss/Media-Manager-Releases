# Media Manager Releases

**Español**

Repositorio público de binarios oficiales de **Media Manager** para Windows. Aquí se publican el instalador, la versión portátil y el manifiesto usado por las actualizaciones dentro de la app.

- `MediaManager-Setup-<version>.exe` — instalador recomendado.
- `MediaManager-Windows-portable-<version>.zip` — versión portátil.
- `update-manifest.json` — versión, URL del instalador y SHA-256 para verificación.

Media Manager 1.2.1 incorpora interfaz e instalador en **Español / English** con textos escritos para sonar naturales en cada idioma.
