# Alpizers Releases

## Español

Repositorio público de binarios oficiales de **Alpizers** para Windows. Aquí se publican el instalador, la versión portátil y el manifiesto HTTPS usado por las actualizaciones dentro de la app.

A partir de Alpizers 1.4.0, los assets usan estos nombres:

- `Alpizers-Setup-<version>.exe` — instalador recomendado.
- `Alpizers-Windows-portable-<version>.zip` — versión portátil.
- `update-manifest.json` — versión, URL del instalador y SHA-256 para verificación.

Las releases 1.3.x y anteriores se publicaron bajo el nombre histórico **Media Manager** y conservan sus nombres originales por integridad del historial y compatibilidad con instalaciones existentes.

Alpizers mantiene interfaz e instalador en **Español / English**, con textos redactados para sonar naturales en cada idioma.
